# 脚本说明

这个目录包含了用于构建和预览静态导出的脚本。

## 脚本列表

### 1. build-static.sh
用于构建静态导出版本的脚本。

**功能：**
- 临时重命名 proxy.ts 文件（静态导出不支持中间件/代理）
- 临时移除 API 路由目录（静态导出不支持 API 路由）
- 清理 Next.js 缓存
- 执行构建
- 恢复所有文件

**使用方法：**
```bash
pnpm run build:static
```

### 2. serve-static.sh
用于预览静态导出结果的脚本。

**功能：**
- 启动一个简单的 HTTP 服务器来预览 out/ 目录中的静态文件
- 默认端口：8080

**使用方法：**
```bash
pnpm run serve:static
```

## 注意事项

1. 这些脚本专门用于静态导出，不会影响正常的开发服务器或生产服务器构建
2. 构建完成后，静态文件将输出到 `out/` 目录
3. 静态导出不支持以下功能：
   - API 路由
   - 中间件/代理
   - 图像优化
   - 国际化路由（但页面内容仍会正确渲染）

## 切换回服务器渲染

如果你需要切换回服务器渲染模式，只需：
1. 恢复 next.config.ts（移除静态导出配置）
2. 使用 `pnpm dev` 启动开发服务器
3. 使用 `pnpm build && pnpm start` 构建并启动生产服务器
